PC ↔ 휴대폰 동기화

Supabase 연결 상태를 확인하는 중…
같은 Supabase 계정으로 PC와 휴대폰에서 로그인하면 저장된 기본정보와 5종 양식 자료를 서로 동기화합니다. 로그인하지 않은 상태에서도 기존 기기 저장(localStorage)은 계속 사용할 수 있습니다.

현재 기본정보

📂 저장된 문서

각 서식 화면에서 [💾 문서 저장]으로 보관한 문서입니다. [열기]를 누르면 해당 서식에서 불러와 이어서 편집할 수 있습니다. 로그인되어 있으면 PC·휴대폰에서 같은 문서함을 사용합니다.

백업 · 복원

진단서, 처방전, 진료부, 기초현황조사표, 나무의사 소견서 및 기본정보를 하나의 JSON 파일로 백업합니다.

동기화 대상

🩺 진단서diagnosis-form-v1
💊 처방전rx-form-v1
📋 진료부jinryobu
🌳 기초현황조사표tree-survey-v1
📝 나무의사 소견서tree-opinion-v1
📂 저장된 문서(문서함)tree_documents 테이블 · 서식별로 여러 건 저장
👤 기본정보treeDiagnosisProfile

주의

Supabase에는 로그인한 사용자 본인의 자료만 접근하도록 RLS를 적용합니다. 브라우저에 service_role/secret key를 넣으면 안 됩니다. 현재 버전은 큰 사진 데이터가 포함된 자료가 너무 크면 해당 항목을 클라우드 동기화에서 제외하고 기기에는 그대로 보관합니다.
